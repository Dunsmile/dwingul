# 구현 참고 기록 — 2026-09-13

- [사주아이](https://saju-kid.com/): 생년월일·시각을 입력하는 서비스 흐름 참고. 결과 문구와 디자인을 복사하지 않았습니다.
- [도파민 공작소](https://dopaminfactory.site/): 확인 시 현재 사이트는 토론·밸런스 흐름이었습니다. 사용자가 설명한 이전 운세 형태와 이름·생일·시각 요구를 구현 기준으로 삼았습니다. 이전 pages.dev 주소는 이번 조회에서 정상 확인되지 않았습니다.
- [Mensa IQ Challenge](https://www.mensa.org/mensa-iq-challenge/), [Mensa — What is IQ?](https://www.mensa.org/what-is-iq/): 연습과 표준화 검사의 구별. 문항을 복사하지 않고 수열·행렬·공간·논리 문제 20개를 작성했습니다.
- [lunar-javascript 공식 저장소](https://github.com/6tail/lunar-javascript): 달력·간지 계산, v1.7.7, MIT. 배포본과 라이선스는 public/js/lunar.js, public/assets/lunar-LICENSE.txt에 포함합니다.
- [인천 행정체제 개편 안내](https://www.incheon.go.kr/IC010601/2187729): 2026년 7월 개편을 반영해 인천 지역 선택을 조정했습니다.

좌우 분류와 레이싱은 사용자가 지정한 ‘삼촌의 니편내편’, ‘다함께 차차차’의 조작 취지를 참고합니다. 해당 게임의 자산·소스·음원을 사용하지 않으며 동일 게임 복제를 표방하지 않습니다. 이번 뒹굴은 독자적인 그림·속도·난이도 규칙을 갖습니다.
