# 뒹굴 게임 확장 v4

사용자의 상세 지정과 기존 자율 구현 승인에 따라 로컬 앱까지 완성한다. 콘텐츠 ID와 저장된 기록은 유지하며 새 규칙의 랭킹을 구분한다.

## 확정 구현

1. 좌우로 쏙쏙: 시작 전에 10초/무한 선택. 잘못 분류하거나 바닥으로 놓친 횟수를 합쳐 3번이면 종료. 10초는 기존 속도, 무한은 시간에 따라 낙하·등장 속도가 함께 상승한다. 중앙 한 줄과 충분한 간격을 유지한다.
2. 타이핑 마스터: 시작 전에 타이포 레인/타이포 RPG 선택. 레인은 기존 100문장 낙하. RPG는 창작 캐릭터·몬스터 전투, 타자속도·정확도·콤보·HP/MP, 타이핑 공격, 몬스터 반격, MP가 가득 차면 빈 입력창에 '힐' 후 Enter로 HP30 회복, Esc 입력 삭제. 100문장을 비복원 사용하며 문장 완료/전투 진행·게임 종료가 실제로 동작한다.
3. 도심 질주: 2.5D 원근 도로 5차선. 좌우 화살표 차량 선택: 기본(속도1, 연료30), 스피드(1.5,25), 롱런(0.8,40); 2·3번 각각50토큰 해금, 4번이후는 준비중. 모은 동전1개=차고 토큰1개, 게임 종료 시 자동 적립(랭킹 등록과 독립), 중복 적립 금지. 기본차 무료, 해금은 서버에 영구 저장한다. 연료 초당1 소모, 아이템+15(차량 최대량 제한). 부스터10칸 충전시 직접 버튼/Space로 사용, 속도2배·초당게이지2 소모(기본5초), 안전한 근접 추월마다1칸 회복하여 지속시간 연장 가능. 회피 중인 동일 장애물 중복보상 금지. 정상 추월 전 실제 충돌을 우선 검사한다. 장애물차량 2~3개 동시, 버스 길이2배, 100개의 고유 패턴을 시드로 섞어 순환. 무조건 피할 수 있는 경로와 전환 시간을 보장한다. 기존 가속계수의1.5배. 거리는 실제 이동속도를 적분한 m.
4. 뒹굴 멀리 뛰기: 기존2단점프/숙이기·목숨2 유지. 기본, 가로2칸, 2단점프 필수 높이, 점프로 넘을 수 없는 슬라이딩 전용 천장 구조 등을 조합한100고유패턴. 시드셔플, 패턴사이 회복시간/예고/가시거리 보장. 거리m가 결과/랭킹값(회피횟수는 보조).

## 연결 계약

- mountGame 옵션에 settings 전달. ctx.settings로 각 게임의 선택을 받는다.
- sort: settings.mode='sprint'|'endless'; typing: settings.mode='rain'|'rpg'; racing: settings.car='basic'|'sport'|'touring'. 기본값은 각 첫 옵션.
- 결과모드: sort-sprint-v4 / sort-endless-v4 / typing-rain-v4 / typing-rpg-v4 / city-basic-v4 / city-sport-v4 / city-touring-v4 / jump-distance-v4.
- 실행 직전 설정을 확정해 run에 저장. 친구방/공유의 옵션도 유지하며 서로 다른 모드의 순위를 혼합하지 않는다. 해금되지 않은 차량은 시작을 막고 차고를 안내한다.
- 토큰 지급은 로그인/프로필 입력 없이 기존 기기 세션에 귀속. 모은 동전의 기본 범위·시드별 가용동전 수 검증, 실행당 한 번만 적립, 차량 해금 원자적 차감. 공개 서비스용 완전한 게임 리플레이 방어를 주장하지 않는다.

## 구현 순서 및 검증

- 독립 작업: 멀리뛰기 패턴/물리/게임, 그다음 타이포RPG 모듈. Root: 설정/차고/데이터/좌우/도심질주 통합. 읽기전용 검토로 명세·품질 확인.
- 수학/상태검사: 패턴 각100고유·안전성, 3회종료, 가속, 차량연료/속도, 연료15, 부스터10→초당2/근접+1, 점프유형별통과가능성, RPG타자·회복·종료.
- 실제 브라우저: 모바일320/390 및 넓은PC에서 설정→플레이→종료→재시작→기록, 토큰적립/해금/새로고침, 친구조건, 캔버스 상태/스크린샷 확인. 테스트서버는 별도 메모리DB. 사용자4173 DB보존 후 최신서버 유지.

## 참고

- 사용자 첨부 도심질주 이미지: 도로 소실점, 멀리 있는 차량의 크기, 양옆 건물, 근거리 차량의 시각적 확대를 참고. 직접 그린 차체/건물 사용.
- https://typingrpg.netlify.app/help/help_kor (2026-09-13 확인): 타이핑에 따른 콤보, 속도·정확도·타수, 몬스터와의HP전투, MP충전후힐30, Esc입력삭제를 참고하며 소스/문구/이미지 복제는 하지 않는다.

## 구현 중 확정한 수치와 검증 계약

- 좌우 무한: 300px/s에서 초당 12px/s씩 증가, 최대850px/s. 등장 간격은 이동거리126px로 고정하여 속도와 함께 빨라진다. 오답 후200ms 잠금, 3번째오답 또는놓침에서즉시종료.
- 도심질주: 시작18m/s, 초당1.08m/s 증가(기존6px/s²를1.5배한9px/s²에동일환산 적용), 기본상한42m/s. 이후 차량배율과 부스터2배를차례로적용. 4ms고정물리로 프레임크기와 독립.
- 차량장애물길이4m/버스8m; 플레이어반폭.27차선, 차량.32/버스.36. 실제충돌을먼저확인한뒤 차체꼬리가완전히지났을때최소측면간격0~.45차선이면한번만근접보상. 패턴고유비점유차선최소2개, 미래가속·부스터최대속도기준1.6초+24m 간격.
- 적립은 실행별 입력로그와시드·차량을 같은엔진에서다시재생하여종료·거리·동전·사유확인후한번만지급한다. 기록등록값도확정한거리에서가져온다. 이검사는자동조작/봇탐지나실시간경쟁보증을뜻하지않는다.
- 타자RPG: HP100 MP100, 정확한신규글자MP+2, 오타확정글자HP-2; 콤보정확글자+4/초당-8/오타0. 문장완료공격30+콤보보너스(20이상floor(combo/5), 최대20). 몬스터HP60+처치수×10(최대160), 8초마다8+floor(처치수/3)피해(최대16). 힐+30 HP상한100, MP100소모. 100문장완주/HP0종료. 점수완성문장×100+처치수×50.
- 새실행/새친구방/새공유 설정에version v4를저장한다. 레거시NULL데이터는기존기록분리를유지하며기본선택을안내한다. 친구방과공유실행은서버의고정조건을사용한다.
