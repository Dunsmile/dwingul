# Jump dense course v19 Implementation Plan

**Goal:** 고정된 공간 간격과 다중 장애물 구간으로 3탄부터 어려워지고 6탄에서 실수를 유발하는 다양한 연계를 만든다.

**Architecture:** v18 엔진과 렌더러를 동결한다. v19는 거리로 저작한 복합 구간을 선택하고 이어 붙인다. 가속해도 배치 간격은 벌어지지 않는다. 각 구간은 물리 탐색으로 가능한 조작을 검증하되 실제 게임은 정답 조작을 사용하지 않는다. 시각적 탄수와 난이도는 1000m 경계로 일치시키고 시작 준비구간을 늘린다.

**Tech Stack:** Existing JavaScript canvas, deterministic engine, Node tests, Chromium/WebKit, Cloudflare Workers.

- [x] 기존 규칙 동결 및 고정 거리 복합 구간/단계별 구성
- [x] 물리 탐색으로 구간과 경계 검증, 불가능한 배치는 재조정
- [x] v19 엔진·시작 안전거리·후반 다양성·안내·랭킹 연결
- [x] 주사율/입력/새 패턴/밀도/초반과 6탄 시각 검증
- [ ] 회귀검사, 빌드, 병합, 배포 후 공개 파일 확인

채택하지 않은 대안: 기존 시간 간격만 축소하면 가속시 공간 확대가 남는다. 매번 무작위 개별 장애물을 배치하면 장면 구성과 회피 가능성의 통제가 어렵다. 고정 공간의 검증된 복합 구간을 다양하게 연결하는 방식을 채택한다.

추가 검토 반영: 유사한 행동열도 최근 5개에서 회피한다. 6탄은 3~5연속 천장과 낮은/높은 묶음, 긴 전환을 제공한다. 3~6탄 템포는 1.08/1.16/1.24/1.40이며 월드와 수직 동작에 함께 적용해 장애물 간격과 점프 궤적은 유지한다. 1000m 경계는 완결된 코스 또는 짧은 연결 코스로 맞춘다.
