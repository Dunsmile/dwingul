# 게임 조작감 수정 계획

Goal: 사용자 피드백 6건을 로컬 앱에 반영하고 이전 기록을 보존한다.

## Chunk 1: 물리와 게임 동작
- 레이싱 판정 독립 모듈/회귀 테스트를 하위 실행자에게 할당. root가 games.js 통합 소유.
- 좌우 개별좌표낙하와 가로형캔버스, 보이는타이머, 3회반응, 기억판확장,9패드 구현.
- games.js getState와 정해진시간진행 훅 유지. 일시정지·종료·리스너정리 유지.

## Chunk 2: 연결과 검증
- catalog/app/server/README 안내·결과·랭킹모드 갱신. 이전버전기록 삭제않고 분리.
- npm test, 개정게임 실제브라우저입력·종료·판정회귀, 게임클라이언트스크린샷검토.
- 320×568,390×844,1280×720에서 판/컨트롤 확인. 최신앱열고 로컬서버유지.

검증 완료: 자동17개, 개정6종18뷰포트, 전체20종/78화면, 친구방·공유. 레이싱늦은충돌 수정 전 재현과 수정 후 안전/정면충돌 확인. 출력 output/game-v2 및 tests/*-report.json.
