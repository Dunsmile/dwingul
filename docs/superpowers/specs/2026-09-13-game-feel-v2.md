# 뒹굴 게임 조작감 2차 — 사용자 수정 요청

사용자가 6종 변경을 직접 지정했고 자율 구현·로컬 실행 권한이 이어진다. 추가 승인 질문 없이 구체적인 규칙을 정해 구현한다.

- 좌우: 기존10초 유지. 캐릭터 개별 y좌표와 일정 낙하속도, 시간에 따라 새 캐릭터 등장. 가장 아래 캐릭터를 좌우로 보낸다. 정답 시 다른 캐릭터의 위치가 바뀌지 않는다. 놓친 캐릭터는 바닥으로 빠져나가고 놓침 수 표시. 큰 캐릭터·넓은 가로형 게임판. 버튼·방향키 유지. 기존 순간 정렬 목록은 폐기.
- 타이밍: 목표1~10초 유지, 0.00부터 증가하는 숫자를 크게 표시. 목표는 별도 작은 텍스트. 결과는 멈춘시간 두자리만, 오차 미표시 유지.
- 반응: 유효3회 평균/최고, 조기입력 재시도. 안내·카드·결과·랭킹 모드까지3회로.
- 레이싱: 같은 차선+넓은y범위 대신 실제그림 안쪽 사각형 겹침. 차선이동은180ms수준으로 실제x이동, 충돌도 그x기준. 각 프레임에서 먼저 현재 위치의 사각형 충돌을 검사한다. 충돌 없이 장애물 중심이 플레이어 중심보다 아래로 내려간 경우에만 추월 완료를 영구 표시하고 다시 충돌시키지 않는다. 이로써 중심선을 넘기는 순간 이미 겹치는 정면충돌은 처리하고, 안전하게 지나간 뒤의 늦은 차선변경은 허용한다. 정면충돌·코인·재시작 유지. 지나간차로의 늦은차선이동은 안전.
- 기억판: 5×5(1~3단계),6×6(4~7),7×7(8단계부터). 표적3개로 시작해 단계마다증가(최대16), 표시시간1.2초→최소0.75초. 3번실수종료. 작은폰에서7×7는32px안팎 불가피하므로 테두리간격작게, 실제칸 식별 유지.
- 순서: 3×3, 9개번호·색/위치표시. 1개순서부터매단계하나증가. 깜빡임중입력불가, 오답종료.
- 변경된게임의 새기록은 버전별모드(좌우낙하v2,보이는시계target-v2,반응3회,레이싱v2,기억판확장v2,9칸)로 저장해 이전기록과 혼합하지 않는다. 기존기록 삭제금지.

검증: 변하기전 레이싱 늦은충돌 재현; 좌우정답후 다음캐릭터좌표유지/시간낙하/미스; 실시간타이머 두자리·일시정지; 반응정확히3회; 레이싱정면충돌과추월후차선변경; 기억판단계별25/36/49·오답;9패드보기/정답/오답; 전게임종료·재시작,320/390/1280화면. 개정기록 등록과 구버전 모드분리. 실제localhost 유지.
