# 뒹굴 일러스트 디자인 패키지 · v12

홈페이지의 숲속 픽셀 캐릭터 스타일을 내부 게임, 장비, 타로와 결과 화면으로 확장했습니다. [아트북](https://dwingul.com/artbook/)에서 실제 서비스 이미지를 확인할 수 있습니다.

## v12 배경과 시점

새 배경·오브젝트 20개, 차량 방향 28개, 전투 자세 41개를 추가하여 아트북은 총 615개 항목입니다. 생성 도구는 내장 imagegen을 사용했고, 원본과 최종 프롬프트를 아래 경로에 보관했습니다.

| 경로 | 내용 |
|---|---|
| [scene-sources-v12.json](../../design/scene-sources-v12.json) | 배경·장애물·분석 캐릭터의 8개 생성 원본과 프롬프트 |
| [pose-sources-v12.json](../../design/pose-sources-v12.json) | 차량·전투의 4개 원본, 구도 수정 및 배경 처리 프롬프트 |
| [scenes-v12](../../design/scenes-v12/) | 저장소에 보관한 원본 PNG 12개 |
| [scene-assets-v12.json](../../design/scene-assets-v12.json) | 최종 이미지 89개의 이름·파일 경로·실제 크기 |
| [scenes](../../public/assets/pixel/scenes/) | 게임에서 읽는 최종 PNG 89개 |
| [build-scene-art.mjs](../../scripts/build-scene-art.mjs) | 원본 분리·투명도 인코딩·크기 조정·목록 생성 |

- 점프: 숲 풍경과 이동 거리가 일치하는 흙길, 그루터기·돌담·높은 통나무·매달린 뿌리. 장애물 그림은 실제 판정 영역에 맞춥니다.
- 분류: 앞에 줄 선 친구들을 위한 숲속 우체국. 기억·색·시간·리듬: 각 동작을 위한 책상과 무대. 색 구별에 필요한 칸 색상은 그대로 유지합니다.
- 주행: 승용차·밴·트럭·버스마다 왼쪽 가장자리/왼쪽/정면/오른쪽/오른쪽 가장자리 이미지를 별도로 제작했습니다. 화면 위치와 거리에 따라 고르고, 플레이어 8종은 정후면입니다. 이미지 비율을 유지하고 바퀴를 도로 접점에 맞춥니다.
- 타이핑: 영웅 16종은 오른쪽, 몬스터 25종은 왼쪽을 바라보는 전투 전용 자세입니다. 선택·도감·성향 결과는 기존 정면 초상을 사용합니다.
- 운세: 책을 읽는 분석 캐릭터와 작은 결과 초상, 해석 본문을 함께 배치합니다.

일부 생성 도구 출력은 투명도를 요청해도 바둑판이 그려진 RGB였습니다. 이 출력은 배포하지 않았습니다. 도구로 배경을 단색 크로마 키로 다시 제작한 뒤, 빌드에서 해당 배경을 alpha로 변환합니다. 외곽선·분리·잔여 배경·자연 비율을 확인한 최종 PNG만 사용합니다. 이미지 제작은 내장 도구, 배포용 인코딩과 크기 조정은 Sharp로 재현합니다.

## 구성

- 놀거리의 동작을 보여주는 활성 전용 썸네일 20종, 크기별 WebP
- 기존 숲속 캐릭터 16종을 분리한 선택·결과용 PNG
- 서로 다른 생김새의 몬스터 25종, 보스 표시와 별개인 순수 캐릭터 이미지
- 차량 8종 및 승용차·밴·트럭·버스 장애물 4종
- 무기·방어구·장신구 각 104종, 총 312개 장비 이미지
- 등급별 열린·닫힌 상자 10종, 봉인 상자, 공격·회복 주문과 숲속 전장
- 메이저 타로 22장과 카드 뒷면, 오행·동전·연료·부스터 등 UI 그림
- 분류 게임의 하양·파랑·보라 친구별 기본·웃음·울음 표정

장비는 **종류별 5개 형태 × 5개 등급 × 3개 슬롯 = 75개 기본 일러스트**를 제작하고, 기존 312개 아이템 ID와 이름에 맞춰 등급 테두리와 각인 변형으로 구성합니다. 312개를 모두 별도 생성한 원화라고 표기하지 않습니다. 수치와 장착 효과는 기존 데이터가 담당하며, 그림 변경으로 강화·보유 정보가 바뀌지 않습니다.

## 재현 방법

`npm ci` 후 `npm run build`를 실행합니다. 이미지 생성 API나 외부 이미지 호스트 없이 저장소의 원본으로 배포물을 재현합니다.

| 경로 | 역할 |
|---|---|
| `design/atlas-sources-v11.json` | 원본 출처, 프롬프트, 칸 배열 |
| `design/atlases-v11/` | 실제 투명도가 확인된 생성 원본 PNG와 전장 |
| `public/assets/pixel/woodland-pets.png` | 기존 16명 캐릭터 원본 |
| `scripts/build-illustrated-art.mjs` | 투명 여백에 맞춰 이미지 분리·크기 통일·장비 카드 생성 |
| `public/assets/pixel/illustrated/` | 앱과 캔버스에서 사용하는 최종 PNG |
| `scripts/build-artbook.mjs` | 최종 이미지 크기·누락 검증 및 갤러리 제작 |

원본과 생성 PNG를 저장소에 함께 보관합니다. 이전 SVG는 과거 참조와 이미지 로딩 실패 시 대체용으로 유지하며, 아트북의 기본 이미지는 PNG 또는 WebP입니다. 수치 게이지·버튼·문장은 읽기와 조작을 위해 HTML/CSS를 사용합니다. 히어로의 제목만 가독성 좋은 시스템 글꼴로 표시하며, 기존 Galmuri(OFL)는 나머지 UI에서 유지합니다.

## v13 후면 차량과 이미지 전달

현재 도심 질주는 모든 차량을 정후면으로 보여줍니다. v12의 전면·좌우 원본은 제작 이력으로 보관하고, 플레이어 8종 및 승용차·밴·트럭·새 버스 후면만 실제 게임에 사용합니다. 버스 원본과 제작 설명은 `design/scenes-v13/`와 `docs/plans/v13-game-tuning-handoff.md`에 있습니다. 아트북은 종료된 따라해 뒹굴 썸네일을 제외하고 새 버스 후면을 더해 615항목입니다.

원본 PNG 585개에 대응하는 WebP 파일 583개를 `scripts/build-delivery-art.mjs`가 원본 PNG에서 WebP로 만듭니다. 큰 배경과 캐릭터 시트는 품질 88, 작은 캐릭터·장비는 무손실로 인코딩합니다. 원본은 보존하며 내용 해시가 붙은 배포 파일과 매니페스트, 이미지 경로를 치환한 CSS 묶음을 함께 재현합니다. 새 파일 주소에는 1년 immutable 캐시를 적용합니다. 게임은 선택한 캐릭터·차량과 필수 장면만 먼저 준비하고, 이미지 디코딩 뒤 시간을 시작합니다.
