# v17 — 평균 타수·제출 정확도와 급강하 달리기

## 변경

- 타이핑 마스터 종료 카드에 점수와 평균 타자 속도(타/분), 정확도를 함께 표시한다. 모바일에서도 기록과 다음 행동을 쉽게 볼 수 있도록 카드 여백·썸네일을 줄였다. 측정 정보는 내 기록과 통합 프로필에 보관한다.
- 타수는 사용자가 제공한 수식에 따라 두벌식 자모로 환산한다. 한=3, 닭=4, 꽃=4. 한글 조합과 받침 이동을 중복 계산하지 않고 삭제 후 재입력은 센다. 영문·숫자·공백·기호는 1, 제어키는 제외. 일시정지 제외 전체 플레이 시간(읽기·대기 포함)을 분모로 사용한다. 실제 키보드 이벤트 수/한컴 공식 결과와 동일하다고 표기하지 않는다.
- 정확도는 Enter 또는 공격 버튼으로 확정한 원문과 입력의 편집거리 합계를 비교한다. 작성 중 고친 오타는 감점하지 않는다. 빈 입력·힐 명령·변경 없는 중복 Enter는 제외한다. 마지막 치명적 오타도 포함하고 제출한 문장이 없으면 —로 표시한다.
- 제출을 원자적 이벤트로 기록해 기존 전투 판정·MP·한글 IME 처리를 유지한다. 서버에서 재생한 통계를 사용하며 과도한 입력 기록을 제한한다. 원문 입력 로그는 프로필 결과에 저장하지 않는다. 장비·골드·타이핑 랭킹 규칙은 유지한다.
- 멀리 뛰기는 공중에서 ↓ 또는 숙이기 버튼을 누르면 빠르게 내려오고, 누른 채 착지하면 슬라이딩을 이어간다. 시작 속도 260px/s, 10초마다 +28, 최고 480. 기존 3하트·약1000m 회복·6구간을 유지한다.
- 서로 다른 100개 장애물 묶음: 기본/넓은15, 연속 슬라이드40(1–5개), 낮은→2단15, 점프→슬라이드15, 마스터3연계15. 10초부터 일부 점프 전환을 섞고, 2구간부터 일부 급강하 연계, 후반에 전체 묶음을 적용한다. 패턴 안은 촘촘하게, 패턴 간에는 착지/다음 입력에 필요한 간격을 남긴다.
- 새 멀리 뛰기 기록은 jump-distance-v17로 분리했다. v16 엔진을 보관해 예전 기록을 새 난이도와 섞지 않는다. 안내 페이지의 새 조작·결과 해설을 갱신했다.

## 검증

- 전체 283개 단위·API·물리 검사를 통과했다. IME/NFD/겹받침, 오타 수정, 제출/재제출, 치명적 입력, 빈 입력/힐, 서버 재생, 이상 입력 차단, 프로필 복구 포함.
- 타이핑 결과: Chromium/WebKit × 320/390/1440px 6화면에서 정확 입력의 HP 유지, 제출 정확도, 일시정지 시간 제외, 정산 성공, 가로 넘침 없음 확인.
- 멀리 뛰기: 100개 모든 패턴을 실제60fps와 9단계 속도260–480에서 회피 입력 탐색. 실제 Chromium에서 랜덤 묶음 전환으로6000m 무피격, 하트, 모바일 버튼, 키보드, 일시정지 확인. Chromium/WebKit × 390/1440px에서 v16/v17 조작 호환8검사.
- 공식 게임 검증 클라이언트로 점프·급강하 입력 및 이미지 확인. 1000m별 배경과 최고 속도 장애물 화면 직접 시각 검토.
- 빌드: 정적 HTML30개, 아트북651개, 이미지전송621개. 격리된 메모리DB에서만 검증했으며 기존 사용자 서버4173 유지.
