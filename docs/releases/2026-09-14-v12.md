- 개인정보 이용 동의는 기본 해제이며, 생일·시간 원문 기억하기는 독립 선택입니다. 생성된 개인 이력의 보관 방식은 별도로 설명합니다. 공유 요청에는 원문 생일·시간·사주 기둥을 넣지 않습니다.

## 데이터와 복구

이번 버전은 DB 테이블·게임 수치·판정·성장·골드·장비·차량 보유·점수 모드를 변경하지 않습니다. 테스트는 격리된 4174/4176 메모리 DB에서만 진행했습니다. 사용자 4173 서버나 실제 DB를 재시작/초기화하지 않았고, 운영 게임/프로필 테스트 기록을 만들지 않았습니다.

운영 문제로 되돌려야 한다면 위의 직전 v11 Worker 버전을 활성화합니다. 데이터 마이그레이션이나 초기화는 필요하지 않습니다. 기존 GA4/AdSense/도메인 설정은 유지합니다.
