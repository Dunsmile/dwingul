# v21 — 같은 프로필 로그인과 관리자 순위 기록 관리

닉네임과 비밀번호로 동일한 서버 프로필을 여러 브라우저에서 불러온다. 기존 사용자의 식별자·기록·RPG 장비·차량은 그대로 유지한다. 로그인용 닉네임은 NFKC 정규화와 대소문자 통합으로 중복을 막고, 잘못된 비밀번호가 새 가입으로 이어지지 않는다. 새 비밀번호는 15~64자이며 기존 4자리 PIN은 이전 브라우저 또는 복구 코드와 함께 소유권을 확인한 뒤 로그인 정보로 전환한다. 서로 다른 기존 프로필을 자동으로 합치지는 않는다.

관리자 DUNSMILE은 서버의 비공개 초기 설정으로만 생성한다. 이름이나 클라이언트 요청의 역할 값으로 관리자 권한을 부여하지 않는다. 관리자 이름은 비밀 설정이 없는 환경에서도 일반 가입에 예약한다. 처음 로그인하면 임시 비밀번호를 바꿔야 기록 관리가 열린다. 정상 운영 중 재시작해도 변경한 비밀번호를 초기값으로 되돌리지 않는다.

관리 화면에서 닉네임·종목을 검색하고 25개씩 조회할 수 있다. 삭제 전 대상 점수, 삭제 사유, 현재 관리자 비밀번호를 확인한다. 삭제와 감사 이력 저장은 하나의 트랜잭션이다. 세계·지역·친구방의 해당 순위 기록만 삭제하며 프로필과 장비는 유지한다. 감사 이력은 식별자·종목·표시 점수·사유·시각을 기록하고 90일 범위를 관리 화면에서 제공한다.

## 로그인과 정보 경계

- 비밀번호: 기존 salted scrypt 저장 방식 사용. 세션 토큰과 복구 코드 원문은 서버에 저장하지 않는다.
- 일반 로그인 30일, 관리자 8시간. 비밀번호 변경·복구·복구 코드 재발급은 모든 이전 세션을 해제하며 현재 브라우저에 새 쿠키를 발급한다. 로그아웃은 해당 브라우저에만 적용한다.
- 이전 토큰이 로그인 계정에 남아 있다면 사용 시 만료가 있는 세션으로 전환한다. 원래 PIN 프로필의 복구 수단은 유지한다.
- 실패 횟수는 SQLite에 해시 키로 보관하고 계정과 IP별로 제한한다. Cloudflare의 [CF-Connecting-IP 문서](https://developers.cloudflare.com/fundamentals/reference/http-headers/)를 확인했다. 공개 요청은 Worker 경유로만 Durable Object에 전달되며 계정별 제한도 함께 적용한다. 프록시의 IP만으로 신원을 판정하지 않는다.
- 소유자를 확인할 수 없는 이전 localStorage 데이터는 로그인한 계정에 자동 업로드하지 않는다. 설정에서 항목을 확인하고 명시적으로 가져온 개인 기록만 합친다. 공개 랭킹·장비의 소유권 병합은 아니다.
- 관리자 조회에는 공개 순위 정보만 반환한다. 생년월일, 비밀번호 해시, 세션, 개인 결과 이력은 제공하지 않는다.
- 개인정보처리방침·문의 안내·로그인/복구 문구를 실제 흐름에 맞췄다.

## 검증

- 전체 단위·API 검사 306개 통과. 기존 게임 검사에서 신규 가입에 쓰던 PIN4 fixture를 유효한 비밀번호로 바꿨다. 기존 PIN 전환 경계는 별도 테스트로 유지한다.
- 신규 인증 API 9개: 중복/잘못된 로그인, 정규화된 이름, 관리자 예약 이름, 레거시 전환, 역할 조작 차단, 임시 비밀번호 변경, 다른 사용자의 순위 삭제, 장비 유지, 친구방 연결 삭제, 감사 트랜잭션 롤백, 복구 코드·세션 폐기, 재시작 시 초기화 방지, 영속 시도 제한.
- Chromium 1440px, WebKit 390px: 가입, 다른 브라우저에서 같은 주인 복구, 틀린 비밀번호, 기존 로컬 데이터 격리 및 새로고침, 삭제 취소/확인, 강제 비밀번호 변경, 관리자 검색·감사 이력·로그아웃, 가로 넘침 없음. 실제 iPhone 실기기 검증은 아니다.
- 로컬 Workers 런타임 + Durable Object SQLite에서 관리자 로그인·비밀번호 변경·역할 차단·로그아웃 통과. 운영 DB를 이용해 삭제 테스트하지 않았다.
- 배포 전 30개 정적 페이지 빌드, Worker dry-run, 공개 텍스트 자산 134개에서 관리자 비밀번호·초기 해시 미포함 확인.
- 독립 보안 리뷰의 기존 브라우저 데이터 혼합, 관리자 이름 선점, 이전 토큰 만료, 복구 코드 변경 시 세션 유지 문제를 보완했다.

## 운영

배포 및 운영 확인 결과는 완료 후 기록한다. 초기 관리자 자격 증명은 이 컴퓨터의 비공개 파일로 전달하며 저장소·사이트에는 포함하지 않는다.
