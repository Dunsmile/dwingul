# v16 — 주행 밸런스, 여섯 구간 달리기, 구분되는 캐릭터, 검색 안내

## 플레이 변경

- 도심 질주: 길가 소품을 노면과 같은 거리 축으로 이동하고 접지 그림자·깊이 순서를 적용. 연료 소모 초당 1.1, 회복 +8, 첫 연료 220–280m/후속 650–850m 간격. 기본 속도 18에서 초당 0.72씩 최대 48까지 증가한 뒤 차종 배율 적용. 연료 소진 후 650ms 정지 화면을 보여주고 결과로 이동.
- 멀리 뛰기: 체력 3칸, 약 1,000m마다 안전 통로의 하트로 한 칸 회복. 1,000m 단위 여섯 구간과 단계별 장애물 구성을 적용. 구간별 목표 빈도 ×1.2, 10초별 가속/빈도 증가를 함께 적용하되 최소 회피 간격과 최고 속도 제한을 유지. 150ms 착지 입력 버퍼와 키 누름/해제 추적으로 입력 누락을 완화. 상단 중복 상태는 숨기고 일시정지 유지.
- 좌우로 쏙쏙: 파란 각진 여우/하얀 둥근 구름의 실제 원화 6종. 논리 큐는 즉시 갱신하고 보충 애니메이션만 입력 속도에 맞춰 72–220ms로 조절. 연속 입력은 애니메이션 완료를 기다리지 않음.
- 새 원화 36개(배경 5, 지면 5, 장애물 20, 캐릭터 표정 6)를 런타임·사전 로딩·아트북에 연결. 제작 프롬프트와 소스는 `design/scene-sources-v16.json`, 산출물 목록은 `design/scene-assets-v16.json`. 이미지 생성 도구로 제작한 원화를 투명 영역에 맞춰 분할·압축. 다음 달리기 구간만 미리 로드.
- 새 주행/달리기는 v16 기록으로 분리. 기존 v7 주행, v13/v11 달리기 엔진을 보존해 이전 기록의 규칙이 바뀌지 않음. 서버 정산과 랭킹·초대/친구방도 버전 구분.

## 검색 접근성 및 피드백 검증

- 실제 계정 확인에서 서치콘솔 등록과 HTTPS sitemap 제출은 이미 완료되어 있었음. 9월14일 sitemap 읽기 성공, 당시 31개 발견. 홈은 ‘발견됨 — 현재 색인이 생성되지 않음’이고 아직 수집 이력이 없었음.
- 9월15일 00:41 KST Google 실시간 URL 검사는 ‘URL을 Google에 등록할 수 있음 / 색인 생성 가능’. 홈·robots·sitemap·주행 안내·ads.txt GET은 일반 UA 및 Googlebot/광고봇 UA 모두 200, 챌린지 없음. UA 변경만으로 Google 실제 접근을 증명하는 것은 아니므로 실시간 검사 결과도 함께 확인함.
- Cloudflare 공격 방어 비상 모드 꺼짐, 사용자 차단 규칙 없음. AI 학습용 봇 차단과 Google 검색 수집은 구분. 방화벽 보호를 불필요하게 해제하지 않음.
- AdSense 화면은 ‘준비 중’, ads.txt ‘승인됨’. 현재 확인된 거절 사유 없음. 과거 Azure 글은 이전 도메인 이력이며 지금의 게임 콘텐츠 전문성을 증명하지 않음.
- 실제 서비스별 20개 정적 안내에 입력 방법·플레이 예시·결과 읽기·수정일을 보강하고 게임 상세에서 연결. 삭제한 리듬을 제외한 9개 게임/20개 콘텐츠 숫자 통일. sitemap 수정일은 해당 문서 변경일만 반영. 실제 안내 문서 20개를 담은 RSS 추가.
- `site:` 검색 결과 수만으로 전체 색인이나 봇 차단을 단정할 수 없음. [Google 설명](https://developers.google.com/search/docs/monitor-debug/search-operators/all-search-site). [sitemap/RSS 공식 지침](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap). [AdSense 크롤러와 검색 크롤러의 구분](https://support.google.com/adsense/answer/99376?hl=en).
