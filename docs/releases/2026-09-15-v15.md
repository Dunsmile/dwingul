# v15 — 타이핑 마스터 메뉴와 긴 문장 모드

## 변경

- Safari의 기본 녹색 둥근 `<meter>` 대신 HP/MP 공통 게이지를 적용했습니다. 플레이어와 몬스터 HP는 같은 높이·색·각진 외곽선이며 접근성 값도 함께 갱신합니다.
- 숲 배경 위에 타이틀과 세로 메뉴를 배치했습니다. 모험 설정, 뽑기 상점, 내 장비, 캐릭터, 프로필이 같은 프레임 안에서 열리고 긴 목록만 내부에서 스크롤합니다. 메뉴 왕복·뽑기 종료·프로필 저장 후에도 문장 모드를 유지합니다.
- 짧은 문장 100개는 기존 공격 규칙과 기록 키를 유지합니다. 긴 문장 250개는 공백 포함 20–30자이며, 장비와 콤보까지 합한 최종 공격을 2배로 계산합니다. 반격과 회복 규칙은 같습니다.
- 긴 문장은 전통 속담 50종을 상황별로 재해석한 200문장과 창작 지혜 문장 50개입니다. 현대 명언 인용집이나 인물 발언으로 표시하지 않습니다. 출처·편집 원칙은 `docs/content/typing-long-phrases-v15.md`에 기록했습니다.
- 긴 문장은 `typing-rpg-v5-long-s{startStage}`로 순위를 구분합니다. 서버는 저장한 런 설정으로 문장과 전투를 재생해 보상을 검증합니다. 친구방·공유도 문장 모드를 유지하고 기본 장비·1스테이지 조건으로 맞춥니다. 골드·장비·열린 스테이지는 두 모드에서 공유합니다.
- 프로필 기록 복구 시 문장 모드가 빠지는 경로를 수정했습니다. 작은 PC 화면의 설명 열기 시 내부 스크롤 이동, 좁은 모바일에서 HP 숫자가 게이지와 겹치는 문제도 함께 해결했습니다.

## 검증

- 전체 단위/API 테스트 250개 통과: 250문장 중복·길이, 두 모드 피해, 재생·체크포인트·정산·랭킹, 방·공유, 프로필 복구와 기존 기능.
- Chromium/WebKit 각 6해상도(1440/1280/1024/768/390/320)에서 메뉴·설정·캐릭터 구매/장착·프로필 저장·긴 문장 공격·공통 게이지·일시정지·설명 고정 확인.
- 두 엔진에서 10회 뽑기, 즉시 장착, 필터, 강화, 명시적 삭제, 도감, 모드 유지 확인.
- 기존 한글 조합/NFD/정확 입력/오타 수정/확정 오타/힐15/반격 검사와 짧은 문장 6해상도 검사를 재실행했습니다. 공식 게임 클라이언트로 긴 문장 초안 입력을 검증하고 화면을 직접 확인했습니다.
- 증거: `output/v15/`, `output/v14/`. 모든 플레이·프로필 테스트는 격리 메모리 DB입니다. 사용자 로컬4173 및 운영 기록에 테스트 데이터를 넣지 않았습니다.
