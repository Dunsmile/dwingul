# v21.1 — 비밀번호 4~15자

사용자 요청에 따라 신규 가입·기존 PIN 전환·비밀번호 변경에서 새 비밀번호 길이를 4~15자로 수정했다. 문자·숫자를 사용할 수 있으며 기존의 추측하기 쉬운 값 차단, 로그인 시도 제한, 서버 권한 검사는 유지한다. 가입·변경 화면의 입력 제한과 안내, 개인정보처리방침을 함께 갱신했다.

기존 15자 초과 비밀번호와 이미 발급한 관리자 임시 비밀번호는 계속 인증할 수 있다. 로그인·현재 비밀번호 확인·복구·기록 삭제 확인 입력은 기존 길이를 허용하고, 새로 설정하는 비밀번호만 4~15자로 제한한다. 실제 계정 비밀번호나 초기 비밀번호를 강제로 변경하지 않았다.

검증: 길이 경계 3/4/15/16자를 가입·변경·기존 프로필 전환에 적용해 확인했다. 긴 관리자 임시 비밀번호로 로그인 후 4자 비밀번호로 변경하는 서버 검사, Chromium PC·WebKit 모바일에서 4자 가입 및 15자 비밀번호 변경·관리자 기능 검사를 통과했다. 기존 게임/프로필 테스트의 신규 계정 fixture도 현재 정책에 맞췄다. 정적 페이지 빌드를 완료했다.
