# v14 — 타이핑 입력과 고정 픽셀 전투 화면

## 수정

- 조합 상태 표시가 누락된 한글 입력을 재현했습니다. 최종 문장은 정확해도 자음 중간 값 때문에 HP가 100→88로 줄었습니다. 입력 경계에서 미완성/수정 초안을 분리하고 NFC 정규화합니다. 정확한 접두부의 MP는 즉시 충전하며, 오타 피해는 공격으로 확정한 문장에만 적용합니다. 동일 재현에서 HP100 유지 확인.
- 전투 모델/반격 시간/힐15/서버 재생 검증 규칙은 바꾸지 않습니다. 중간 초안이 서버 입력 기록에 오타로 들어가지 않도록 UI 경계를 수정했습니다. 실제 오타가 남은 공격에는 차감 HP를 명시합니다.
- PC 전투 영역은 화면 높이에 따라420~560px, 기본 영웅/몬스터 최대136/144px로 축소했습니다. 1440×900에서 기존710px→560px, 영웅188px→136px입니다.
- 상단 중앙의 일시정지/계속하기 버튼을 유지하고, 상태창·게이지·입력창·설명을 기존 종이색/갈색 외곽선/각진 픽셀 스타일로 통일했습니다.
- 하단 설명은 내부 스크롤 가능한 패널로 열립니다. 펼침 전후 전투 높이와 입력창의 상대 위치가 변하지 않습니다. 작은 모바일에서 버튼을 화면에 넣는 브라우저 스크롤과 실제 레이아웃 변화는 구분해 검사했습니다.

## 검증

- 단위/API240개, 문법 검사 통과.
- 1440×900,1366×768,1280×720,1024×768,390×844,320×568에서 각진 패널, PC 크기, 설명 열기/닫기, 일시정지30초, 재개 후 정확한 공격 확인.
- 한글 중간 자음, Chromium 네이티브 composition 이벤트, 조합 중 Enter, NFD 입력, 오타 수정, 확정 오타4HP 표시, 몬스터 반격/힐15 검증.
- 기존 전투 모델로 새 입력 로그를 재생했을 때 진행 결과 일치 확인. DB 스키마나 사용자 장비·성장·계정 변경 없음.
