# v18 — 멀리 뛰기 행동 연계 도전

## 바뀐 플레이

숙이기를 유지하는 것만으로 긴 슬라이드 구간을 통과하던 문제를 해결한다. 20개의 행동 순서에 폭·높이 변형을 더한 100개 조합을 만든다. 각 조합은 슬라이드, 1단 점프, 2단 점프를 포함하며 4~10개 행동으로 이어진다. 예: 슬라이드 → 점프 → 2단 점프 → 슬라이드, 점프 → 슬라이드 → 2단 점프 → 중간 돌 → 점프. 개별 장애물을 뒤섞지 않고 조합 전체를 고르며, 직전과 같은 행동 순서와 슬라이드 유지로 넘어갈 수 있는 경계는 배제한다.

중간 높이 룬 돌은 새 투명 픽셀 원화를 적용했다. 서 있으면 부딪히지만 점프와 슬라이딩 양쪽으로 피할 수 있다. 외곽과 충돌 범위가 일치하도록 지면·지지대 없는 원화를 사용하고 시작 전 이미지 해독 완료를 기다린다. 아트북과 압축 전송 이미지도 갱신했다.

- 속도310px/s에서 시작해10초마다32씩 증가, 최고630. 기존260→480보다 초반과 최고 속도가 높다.
- 시간22초 또는1000m마다 연계 단계가 올라간다. 후반은 tier4~5의8~10행동 조합으로 구성하며6000m 이후에도 이 난이도를 유지한다.
- 조합 안 불필요한 여유를 줄이고 조합 사이90ms를 둔다. 각 행동은 착지 가능한 시간으로 구성한다. 높은 장애물 뒤에는 급강하로 다음 동작을 연결한다.
- 점프는 누르고 있던 슬라이딩보다 우선한다. 급강하하려면 숙이기를 새로 누른다. 아래쪽 키 자동 반복은 점프를 취소하지 않는다. 다른 손가락을 떼어도 현재 슬라이딩을 취소하지 않는다.
- 공중 급강하 최소 수직 속도760, 중력3200. 물리는 최대1/120초씩 계산해 낮은 화면 주사율에서도 충돌을 놓치지 않는다.
-3하트, 약1000m 회복,6개 배경을 유지한다. 회복 하트는 조합 경계에 짧은 전용 공간을 확보해 배치한다. 피격 무적650ms, 마지막 피격 뒤 지면에서650ms 멈춘 뒤 결과로 이동한다.
- 기록은 jump-distance-v18로 분리한다. v17 엔진과 패턴은 동결하고 진행 중이던 v17 결과는 예전 모드로 저장한다. 규칙 정보 없는 기록은 새 모드를 주장할 수 없다. DB 스키마 변경 없음.

## 검증

- 전체291개 단위·API·물리 검사 통과.
- 모든100개 조합을12개 시작 시점(가속 경계 포함),60/120fps, 중간 돌 위/아래 경로로 검증했다. 전체 입력 시퀀스를-33/0/+33ms 옮긴 경우도 통과했다.
- 실제 엔진에서4개 seed, 총1000개 연속 조합 경계 무피격 통과. 각 주행6000m 이상, 최고 속도, 하트5개 이상 확인. 숙이기 유지·점프 반복·무입력 전략은 각각20개 seed에서600m 전에 종료됨을 확인했다.
- Chromium/WebKit ×320/390/1440px: 터치·키보드, 점프 우선, 새 입력 급강하, 다른 손가락 해제, 일시정지, 가로 넘침 없음, v17 호환을 확인했다. Chromium1440px에서실제 DOM 입력으로6102.2m 무피격,6개 구간/하트6개 확인.
- 공식 게임 Playwright 클라이언트로 점프·급강하 입력과 캔버스 이미지를 별도 확인했다. 중간 돌과6구간 이미지를 직접 검토했다.
- 전체 빌드:30개 정적 페이지, 아트북652개, 압축 전송 이미지622개. 운영 DB에 검증 데이터를 쓰지 않고 메모리DB만 사용했다.
- 근거: output/v18-tests.log, output/v18-build.log, output/v18/browser/report.json, output/v18/official-client/, tests/jump-action-v18.test.mjs. 체감 난이도는 기계적 회피 가능성 검사와 별개이며 실제 사용자의 숙련도에 따라 달라진다.
