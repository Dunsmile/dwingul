# 뒹굴 UI 개선 v7

사용자 승인 범위: 도심 질주 모바일 높이 고정/위쪽 방향키·터치 부스터, 타이핑 마스터 상자 열기 모달과 즉시 장착, 따라해 뒹굴 리듬 게임 재구성, 행동 후 스크롤 복원.

- 화면 탐색은 새 화면일 때만 상단으로 이동한다. 같은 화면의 갱신·탭·필터는 스크롤과 가능한 포커스를 유지한다.
- 도심 질주 상태 문구는 두 줄 공간을 미리 확보한다. 모바일 브라우저 높이 변경으로 게임 캔버스 크기가 바뀌지 않게 한다. ↑/Space 및 모바일 전용 부스터 버튼을 같은 엔진 입력으로 연결한다. 물리·점수 v6 유지.
- 뽑기는 클릭 시 서버의 기존 멱등 키로 한번만 결제한다. 중앙 모달에서 상자를 흔드는 연출 후 사용자가 열어 결과를 본다. 등급 색 테두리·직접 장착·닫기를 같은 모달에 둔다. 오류와 중복 장비 환급을 명확히 표시한다. 모션 감소 설정 지원.
- 리듬 릴레이: 4박자 듣기 → 4박자 따라치기, 8라운드, 96→124 BPM, 점진적 엇박자. 원버튼/Space/Enter, 독창적 합성음, 시각 박자, 판정·콤보·에너지. 새 기록 모드 rhythm-relay-v7로 이전 기억판 순위와 분리한다.
- 4174의 메모리 DB에서 검증하며 사용자 4173 데이터는 유지한다. 모바일 320/390 및 PC 화면, 실제 키·터치, 모달 결과/장착/오류, 같은 화면 스크롤, 리듬 판정·일시정지·완주를 검증한다.
