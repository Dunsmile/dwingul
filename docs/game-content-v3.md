# 뒹굴 플레이·문항 개선 v3

사용자가 지정한 변경을 로컬 앱에 구현한다. 배포나 실제 광고 연결은 포함하지 않는다.

- 좌우로 쏙쏙: 중앙 한 줄, 캐릭터 사이 충분한 간격. 정답 시 나머지 캐릭터 위치는 유지하며 자연 낙하한다.
- 따라해 뒹굴: 9칸 모두 평소 중립색. 순서 표시 및 유효한 입력 때만 해당 칸에 색이 들어온다.
- 문장 벽돌: 직접 작성한 서로 다른 짧은 한국어 문장 100개. 한 판에 중복 출제하지 않고 100개 정리 시 완주한다.
- 이거 누구게?: 드라마·애니·게임 각 100문항. 원문에서 초성 생성, 정답 유일성 검사. 매 판 10문항 비복원 추출.
- IQ 추리: 창작 100문항(수열·행렬·공간·논리 각 25), 유형별 5개씩 뽑아 총 20문항. 문항·보기 순서는 시드로 재현하며 한 판 내 중복 없음.
- 새 게임 '액운 훌쩍': 삐삐사주의 점프·숙이기 메커니즘을 참고한 직접 제작 게임. Space/위/터치 점프, 공중에서 한 번 더 점프, 아래/버튼 유지로 숙이기. 지상 장애물과 공중 구름, 2회 충돌 시 끝. 점차 속도가 증가하고 회피 개수로 비교한다.
- 새 문항 버전과 예전 기록을 구분하고 서버 채점과 친구 도전의 출제를 일치시킨다.
