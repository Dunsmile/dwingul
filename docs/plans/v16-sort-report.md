# v16 좌우로 쏙쏙 작업 보고

## 원인과 구현

- 기존 파랑/하양 캐릭터는 같은 256×256 원화 실루엣을 색만 바꿔 사용해, 빠르게 판단할 때 색상 외 단서가 없었다.
- 기존 큐는 정답 즉시 배열을 당긴 뒤 새 맨 앞 캐릭터를 완성 위치에 그려 순간이동처럼 보였다.
- 기존 오답 화면 효과(`flashMs`)가 160ms 동안 `choose()` 자체를 막아 빠른 연속 입력 일부가 사라졌다.
- 파랑은 뾰족한 귀와 마름모 몸체의 각진 여우, 하양은 귀가 없는 둥근 구름 캐릭터로 교체해 색각과 무관한 실루엣 단서를 추가했다. normal/smile/cry 3표정씩 제공하며 피버의 기존 보라 캐릭터는 유지한다.
- 논리 큐는 입력 순간 즉시 제거/채점하고, 각 남은 캐릭터의 시각 위치만 cubic ease-out으로 앞 슬롯까지 이동한다. 이동 중 다시 입력해도 현재 보간 위치에서 새 목적지로 이어져 점프하거나 입력을 막지 않는다.
- 이동 시간은 직전 정답 간격의 52%를 사용하고 72~220ms로 제한했다. 빠른 플레이에는 짧게, 느린 플레이에는 읽기 좋은 길이로 적응한다.
- 오답 효과는 화면에 남지만 입력 잠금은 제거했다. 3회 실수, 20초, 무한, 피버, 종료 표정과 900ms 종료 정지는 v5 규칙과 결과 모드를 유지한다.

## 검증

- `node --test tests/v16-sort.test.mjs tests/game-v5.test.mjs`: 6/6 통과.
- `node tests/v16-sort-browser.mjs` (메모리 DB, 4183): 320×740, 390×844, 1440×900에서 중간 프레임과 도착 위치, 가로 넘침 없음 확인.
- 같은 브라우저 검사에서 시간 진행 없는 정답 12회 연속 입력, 피버 진입/양방향 허용, 20초 미소 종료, 무한 모드 오답 3회 즉시 입력/울음 종료, 900ms 결과 전환을 확인했다.
- 최종 신규 원화 연결 뒤 위 브라우저 검사를 다시 실행하고 7개 화면을 모두 직접 검토했다. 여우와 구름은 작은 원근 단계에서도 형태가 분명하며, 투명 배경·사각 테두리·캔버스 잘림·표정 누락은 발견되지 않았다. 버튼명 `← 파란 여우`/`하얀 구름 →`도 320px에서 한 줄로 표시된다.
- 개발 게임 Playwright 클라이언트로 짧은 입력 burst 2회를 별도 실행했다. 상태 JSON과 `shot-0.png`, `shot-1.png`를 실제 확인했으며 콘솔 오류가 없었다.
- 화면 증거: `output/v16-sort/fill-{320,390,1440}.png`, `rapid-burst.png`, `fever.png`, `smile-ending.png`, `cry-ending.png`, `skill-client/`.
