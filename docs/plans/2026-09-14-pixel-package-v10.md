# 뒹굴 픽셀 패키지 v10

## 사용자 요청과 제작 방향
홈의 캐릭터 초상 반복을 서비스의 실제 행동을 보여주는 썸네일로 교체한다. 내부 UI와 게임 아트도 같은 숲속 픽셀 RPG 세계로 통일한다. 게임 규칙, 조작, 충돌 좌표, 아이템 ID·확률·저장, 개인정보·측정 동의는 유지한다.

## 미술 규칙
현재 woodland-pets의 둥근 얼굴, 작은 검은 눈, 볼터치, 두세 단계 명암, 계단식 픽셀 윤곽을 유지. 크림 종이 #fff8e8 / 갈색 #49382d / 숲색 #405c3e / 이끼 #91a877 / 금색 #dfb665. 썸네일은 3:2, 캐릭터보다 게임 도구와 동작이 먼저 읽히는 큰 구성, 이미지에 제목을 박지 않는다. 텍스트는 HTML로 접근성을 유지. 레드/그린 신호, 색 찾기 문제 등 판정에 필요한 색은 보존한다.

## 실행 순서
1. 필요 요소 감사 및 목록 확정 (본 문서).
2. 이미지 생성 도구로 서비스별 21개 썸네일 제작, 원본 및 프롬프트 보관.
3. 기존 코드 기반 픽셀 에셋은 제작기를 개선하여 모든 장비·카드·게임 객체 적용. 공통 UI의 규격 통일.
4. 생성 이미지와 내부 에셋을 실제 화면에 연결. 원근/충돌 가독성, 모바일 조작 영역, 글자 가독성 확인.
5. 독립 검토, 320/390/768/1440/1920 화면·게임 실제 입력·API 회귀·정적 링크 검사.
6. GitHub 반영과 Cloudflare 배포, 실서비스 이미지/정적 페이지 응답 확인.

## 완료 기준
21개 썸네일 모두 다른 게임/놀이 내용으로 식별 가능. 플레이 내부도 카드만 테두리를 바꾸는 수준을 넘어 실제 객체에 새 아트 적용. 모든312장비 ID와 데이터 보존. 이미지 실패 폴백 및 lazy loading, 레이아웃 예약으로 흔들림 방지. 새 이미지가 공유/검색 가이드에도 적용. 모바일 주요 시작·정지·확인 버튼44px 유지. 사용자 DB 테스트 금지: 4174의 메모리 DB만 사용.
