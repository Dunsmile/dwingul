# V11 초성 퀴즈 힌트 인계

## 구현 결과

- `guess-hints.js`에 드라마·애니·게임 각 100개, 총 300개의 한국어 맥락 힌트를 추가했다.
- 힌트는 `guess-{category}-{001..100}` ID에 연결하며, 이야기·인물 관계·직업·능력·역할 중 식별에 도움이 되는 정보를 담는다.
- `guess-bank-v8.js`는 힌트 도입 직전의 300문항을 그대로 보존한다. JSON SHA-256은 `f495ef9455dc49b6c9553ea356b4d24222f9b2d98e818dc6b3f4d4cd32af68f8`이다.
- `guess-bank.js`는 보존한 V8 문항에 `hint`만 더한다. ID, 정답, 보기, 정답 위치, 문제 문구와 해설은 바뀌지 않는다.
- 기본 문제 버전은 `initial-clues-v11`, 기록 모드는 `{topic}-initial-clues-v11`이다. 이전 `initial-match-v8`은 `{topic}-initials-v8` 모드로 그대로 재현된다.
- 지원 버전은 `v1`, `pool-100-v3`, `initial-match-v8`, `initial-clues-v11`이다. 이전 공유·친구방의 문항 구성과 기록 모드를 유지할 수 있다.

## 앱·서버 연결

- 질문 객체의 선택 속성인 `hint`를 사용한다. 오래된 버전은 이 속성이 없으므로 별도 마이그레이션 없이 기존 렌더링을 유지할 수 있다.
- 앱은 퀴즈 질문 제목 아래에서 `q.hint`가 있을 때만 `.question-hint`를 렌더링한다.
- 새 실행은 `questionVersion('guess')`가 반환하는 `initial-clues-v11`을 `/api/runs`에 전달해야 한다.
- 카탈로그의 현재 기록 모드는 `drama-initial-clues-v11`이어야 한다. 서버는 `supportedQuestionVersions('guess')`로 새 버전을 허용하고, 친구방 생성 시 같은 버전을 저장한다.
- 현재 작업 트리에서 앱 렌더링, 카탈로그 현재 모드, 서버 버전 검증 연결까지 확인했다.

## 내용 검수

- 300개를 원본 정답·작품 묶음과 한 줄씩 대조했다. 빈 힌트, 중복 힌트, 정규화한 정답 전문 노출은 없다.
- 사실관계 재검수에서 궁중 남장 설정, 외부 태양계 전사 표현, 최신 영웅 기술, 가렌 장비, 카타리나 역할, 바이오하자드 인물 역할, 메타 나이트의 미확정 관계처럼 오해 소지가 있는 문장을 바로잡았다.
- 불명확한 항목은 각 문항에 이미 연결된 공식 작품 사이트를 우선 확인했다. 추가로 Riot Games의 가렌·카타리나 공식 소개, Nintendo의 메타 나이트·마버로아·커비 동료 소개, Netflix 공식 작품 소개를 대조했다.

## 데이터 호환성

- 서버 DB 스키마 변경은 없다. 실행·공유·친구방의 기존 `question_version` 값은 유지된다.
- V11은 V8과 같은 시드에서 같은 문항 ID·보기·정답 순서를 만든다. 리더보드 모드 문자열만 분리되어 힌트 유무가 다른 점수를 섞지 않는다.
- 힌트는 배열 순서에 기대어 임의 결합하지 않고 안정된 문항 ID로 조회한다. 누락된 ID는 빈 문자열을 반환해 오래된 소비 코드도 깨지지 않는다.
