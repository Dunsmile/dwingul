# 픽셀 패키지 v10 화면 검증

검증일: 2026-09-14. 자동 검증은 격리된 `127.0.0.1:4174` 메모리 DB와 Chromium을 사용했다. 실제 사용자 로컬 4173 DB와 운영 기록에 테스트 데이터를 쓰지 않았다.

## 범위와 결과

- 320×568, 390×844, 768×1024, 1440×900, 1920×1080에서 홈·둘러보기·21개 상세: 115개 화면 검사.
- 각 화면폭에서 21개 썸네일이 모두 서로 다르고 정상 로딩, 가로 넘침 없음.
- 게임 10개 실제 입력: 좌우 분류, 보이는 초 타이머, 색 찾기, 반응속도, 타이핑 공격, 주행, 기억판, 숫자판, 리듬 응답, 점프/숙이기.
- 도심 질주: 저장된 재현 입력으로 10회 회피 후 PC ↑와 모바일 부스터가 작동. 차량 7종의 실제 아트 파일과 부스터 아이콘 로딩. 노면 접점·차체 길이·지나침 판정 유지.
- 멀리 뛰기: 모바일 논리 화면640폭, PC1080폭. 달리기/점프/슬라이딩/착지 후 X눈/결과 전환 확인. 모바일 캐릭터가 기존 대비 약1.69배 크게 표시.
- 퀴즈10문항 완료 → 실제 공유 생성 → 공유받은 화면의 썸네일 로딩.
- 성향12문항 완료, 개인 결과 초상, 운세 입력·결과, 타로 선택·앞면 결과.
- 의도적으로 막은 썸네일과 성향 결과 이미지가 대체 표시로 바뀌며 결과 텍스트 유지.
- 아트북: 390/1440에서 482개 제작물, 6개 분류, 한국어 ‘타로’ 검색23장, 키보드 초점과 원본 이미지 링크, 가로 넘침 없음.
- 장비 필터·장착·희귀 뽑기 모달, 스크롤 유지. 별도 RPG 검증에서 실제 영웅/일반 적/10스테이지 보스/신 등급 상자 확인.
- 단위·API·자산 무결성 검사147개 통과. 모든 캐릭터 원화의 실제 알파 채널, 312장비 고유성, 25일반/25보스 도달 경로, SVG 안전성과 실제 치수 확인.
- Cloudflare 로컬 실행 환경4175: 정적 리소스507개와 대표 가이드3개 HTTP200, 페이지 스크립트/CSP 오류 없음.

## 검토에서 수정한 내용

작은 모바일 점프 캐릭터를 확대하고 새 동작 이미지를 연결했다. 차고만 사용하던 차량 그림을 실제 주행에도 투영했다. 공유 결과 썸네일, 결과·차고·갤러리의 이미지 오류 대체, SVG 실제 비율, 아트북의 한국어 검색을 보완했다. 두 포즈에서 생성된 가짜 투명 배경은 재제작했고 최종 원화11개 모두 알파 채널을 검증했다.

초기 브라우저 검사에는 비동기 이미지 대기, 공유 제목 선택자, 장비 필터 갱신 대기의 테스트 코드 오류가 있었다. 제품 오류와 구분하고, 제한 시간이 있는 이미지 로딩 확인과 새 화면 갱신 대기로 고쳤다. 최종 전체 실행에서 115개 화면, 게임 확인13항목, 결과5종, RPG 장비·뽑기, 아트북을 모두 통과했고 findings는 빈 배열이다.

## 증거와 재실행

`output/playwright/v10-world/` 아래의 최종 `report-full.json`, 분할 실행 `report-artbook.json`, `report-results.json`, `report-rpg.json`, 화면별 PNG를 사용한다. 테스트 결과와 스크린샷은 Git에 올리지 않는다. 주요 이미지: `home-390`, `explore-1440`, `city-390`, `jump-390`, `jump-slide-390`, `jump-end-x-390`, `rhythm-390`, `shared-result-thumbnail-390`, `result-decorative-fallback-390`, `artbook-390`, `artbook-worker-1440`, `guide-worker-1440`.

```sh
DW_DB=:memory: PORT=4174 npm start
node tests/v10-world-browser.mjs
QA_SECTION=artbook node tests/v10-world-browser.mjs
QA_SECTION=results node tests/v10-world-browser.mjs
npm test
npm run build
```

개발용 게임 클라이언트(공식 skill 스크립트와 동일)로 도심 질주와 2단 점프를 추가 실행했고, 출력 PNG와 `render_game_to_text` 상태를 직접 확인했다. 공개 배포 후에는 데이터 변경 없는 `node scripts/verify-public-art.mjs`로 정적 파일만 확인한다.
