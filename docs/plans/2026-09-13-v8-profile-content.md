# 뒹굴 v8: 문항 품질과 공통 프로필

## 결정
- 초성 퀴즈는 네 보기 모두 초성·띄어쓰기·글자 수를 일치시키고, 기존 문제 묶음은 v3로 보존한다. 새 모드는 별도 랭킹을 쓴다.
- 생일은 8자리 숫자 입력, 시간은 24시간 시·분 선택과 모름 선택. 단톡방과 사업가 유형 테스트는 닉네임과 답변만 사용한다.
- 공통 프로필은 기존 users.id를 유지한다. 가입 전 쌓은 RPG 성장·아이템·차량을 그대로 연결하고, 모든 콘텐츠의 개인 결과를 최근 100개까지 복구한다. 공개 랭킹 등록은 계속 별도 선택이다.
- 생일 기억은 명시적인 선택이다. 기존 브라우저에 기억한 생일은 동의 없이 서버로 옮기지 않는다. 프로필에서 삭제·불러오기·다른 사람 입력을 지원한다.
- 프로필 복구 때 이전 사용자의 브라우저 캐시를 분리해 계정 사이에 생일·기록이 섞이지 않게 한다.

## 참고
- https://testmoa.com/business-type/ : 상황에 따른 사업 태도와 여러 유형의 비중을 해석하는 형식 참고. 뒹굴은 별도의 12개 상황·4가지 선택·4개 유형과 실천 제안을 작성한다. 검증된 직업 적성 검사로 표현하지 않는다.
- https://sajuday.kr/ : 8자리 생일, 시·분 및 시간 모름 입력 방식 참고.

## 구현 및 검증
1. 동일 초성 보기 300문항, 기존 버전 재현성 확인.
2. 사업가 질문·결과 및 공통 날짜 정규화/검증.
3. 사적 프로필·이력 API와 기존 데이터 유지, 계정별 접근 및 복구 검증.
4. 공통 프로필 화면·폼 불러오기·결과 저장 통합.
5. 격리 서버에서 모바일·PC 사용자 흐름과 기존 테스트 실행. 운영 DB 백업 후 재시작, 보존 확인.
