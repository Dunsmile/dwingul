# v18 중간 높이 장애물 아트

## 결과

- 최종 파일: `public/assets/pixel/scenes/jump-obstacle-middle.png`
- 원본 생성 크기: 1380×1140 RGBA PNG
- 최종 크기: 256×217 RGBA 팔레트 PNG
- 용도: 약 64×62 표시 크기의 중간 높이 장애물. 플레이어가 위로 점프하거나 아래로 슬라이드할 수 있도록 게임에서 공중에 배치한다.

## 시각 선택

짧고 넓은 고대 룬석에 이끼와 작은 잎이 직접 붙은 형태다. 외곽은 어두운 갈색 픽셀선, 돌은 따뜻한 회갈색, 식생은 기존 숲 배경과 같은 올리브·초록 계열이며 중앙 잎 룬은 옅은 금색으로 읽힌다. 전체 외곽이 단단한 직사각형에 가까워 충돌 범위를 예측하기 쉽다. 바닥, 그림자, 받침, 밧줄, 사슬은 포함하지 않았다.

## 생성 정보

- 방식: 내장 image generation 도구로 새 이미지를 생성한 뒤 투명 픽셀 경계로 자르고 최근접 보간으로 축소했다.
- 최종 프롬프트 요약: 투명 배경의 단일 공중 이끼 룬석, 횡스크롤 러너의 옆 시점, 단단한 직사각형 충돌 실루엣, 따뜻한 숲 팔레트와 굵은 픽셀 스타일, 중앙 잎 룬, 64×62와 48px에서 판독 가능, 지면·지지대·줄·문자·UI 금지.

## 검증

- 최종 PNG는 4채널 알파를 포함하며 전체가 불투명하지 않아 실제 투명 배경임을 확인했다.
- 투명 경계 기준으로 자른 뒤 좌우 4px, 위아래 5px의 작은 안전 여백만 남겼다.
- 64×62와 48×47 최근접 축소본을 직접 확인했다. 두 크기 모두 중앙 룬, 돌 외곽, 이끼가 구분되고 긴 돌출부나 잘린 부분이 없다.
- 게임 코드, 장면 매니페스트, 빌드 스크립트는 수정하지 않았다. 상위 작업에서 장면 로더와 중간 장애물 렌더러에 이 파일을 연결해야 한다.
