# 뒹굴 v9 출시 구현 계획

사용자 요청: 게임 개선·픽셀 디자인·협업 저장소·클라우드 DB 및 배포·dwingul.com·GA4/AdSense/Search Console 연결까지 수행.

기존 실행본과 데이터를 건드리지 않는 별도 출시 작업 폴더. 개인 DB, 복구 코드, 테스트 산출물·스크린샷·토큰은 Git에 올리지 않는다.

  - [x] 카탈로그 312개, 기존 ID·이름·성능, 아이콘 URI 계약 구현 및 단위 테스트.

  - [x] 저장소 스키마 마이그레이션, 단일·묶음 멱등 키, 원자적 차감, 수량 누적 구현.
  - [ ] 앱 이벤트와 공개 API 라우트 연결 후 브라우저 통합 검증.
- [ ] 강화 +0~+10. 대표 장비 1개와 동일 ID 여분 2개를 합쳐 +1, 100% 성공. 효과는 기본값×(1+0.1×강화단계) 반올림. 여분은 강화되지 않은 재료로 표기. 장착 중 강화도 반영, 진행중 게임은 시작 스냅샷 유지.
  - [x] 저장소 검증·트랜잭션, 장착 능력치 반영, 장비 UI와 앱 연결용 속성 구현.

  - [x] 필터·6행 페이지·도감·삭제 확인용 데이터 속성 구현.
  - [ ] 앱에서 등급 선택 이동과 삭제 확인 대화상자·API 호출 연결.
- [ ] 10개 순차 수동 공개, 희귀 이상만 추가 흔들림. 닫으면 미공개 상자 복원, 추가 차감 없음. 종료버튼 홈으로 가기(타이핑 홈). 프로필 details 기본접힘.
