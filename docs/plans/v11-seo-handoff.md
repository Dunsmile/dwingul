# v11 정적 검색 페이지 인계

## 반영한 내용

`scripts/build-site.mjs`는 홈, 가이드 목록, 장르 4개, 콘텐츠 21개, 안내·정책 4개를 합친 31개 정식 주소를 `dist`에 만든다. 각 주소는 하나의 canonical, 고유한 제목과 설명, 색인 가능한 본문을 가진다.

콘텐츠 페이지에는 `WebPage`, `WebApplication`, `BreadcrumbList` 구조화 데이터를 넣는다. 가이드 목록과 장르 페이지는 `WebPage`, `ItemList`, `BreadcrumbList`, 안내·정책 페이지는 `WebPage`, `BreadcrumbList`를 사용한다. 홈은 `WebSite`와 `WebPage`를 연결한다. 실제 이용자 평가 데이터가 없으므로 별점, 리뷰 수, `AggregateRating`은 만들지 않는다.

모든 정적 페이지에는 `poilkjmnb122@gmail.com`을 화면에 보이는 이메일 링크로 표시하고 `© 2026 DWINGUL`을 넣었다. 문의 수단을 GitHub Issues로 소개하지 않는다. 콘텐츠 목록은 네 장르 페이지를 링크하고, 각 장르 페이지는 소속 콘텐츠 전체를 링크하며, 각 콘텐츠의 breadcrumb는 해당 장르로 돌아간다.

## v11 안내 동기화

- 도심 질주: 8종 차량, 초당 0.5 연료 감소, +15 연료, 충돌 기본 -10과 장갑 완화, 0.9초 보호, 연료 0 종료, 차량별 부스터와 50~200토큰 가격
- 따라해 뒹굴: 왼쪽·가운데·오른쪽 세 레인, 각 키 입력, 100가지 박자 패턴과 무한 에너지 방식
- 뒹굴 멀리 뛰기: 바닥과 장애물의 공통 거리 축, 속도가 오를수록 짧아지는 시간 간격, 두 번째 충돌 종료
- 타이핑 마스터: 전투 능력에 영향 없는 16종 캐릭터, 순환하는 25종 몬스터, 기존 장비·보스 진행
- 사업가 유형: 12개 네 선택 상황, 네 사업 방식의 비중, 16가지 주·보조 조합과 동률 설명

이 다섯 콘텐츠는 정적 가이드 전용 `rules`를 명시해 공용 카탈로그 문구가 배포 시점에 늦게 갱신되어도 오래된 규칙이 검색 페이지에 다시 나타나지 않게 했다. `public/js/search-metadata.js`의 검색 제목과 설명도 같은 내용으로 맞췄다.

## 검증

`tests/build-site.test.mjs`는 실제 빌드를 만든 뒤 다음을 확인한다.

- 공개 페이지 31개와 카탈로그 21개
- 31개 canonical의 정확한 주소, 서로 다른 제목·설명, 충분한 설명 길이
- 모든 페이지의 `WebPage`, 콘텐츠의 `WebApplication`, 홈을 제외한 페이지의 `BreadcrumbList`
- 가짜 별점·리뷰 구조화 데이터 부재
- 장르와 콘텐츠 사이의 크롤 가능한 링크
- 모든 페이지의 이메일과 저작권 표기, GitHub Issues 문의 문구 부재
- v11 게임·테스트 핵심 규칙과 오래된 도심 질주 문구 부재
- 서버 전용 차고·RPG 저장소 파일의 배포 제외, ads.txt와 사이트맵

실행 결과: `node --test tests/build-site.test.mjs` 1개 테스트 통과. 이 테스트 안에서 31개 페이지와 21개 콘텐츠를 전부 순회한다. 문법 검사는 `scripts/build-site.mjs`, `public/js/search-metadata.js`, `tests/build-site.test.mjs` 모두 통과했다. 배포나 실제 검색 색인 확인은 수행하지 않았다.
