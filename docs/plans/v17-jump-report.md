# v17 멀리 뛰기 구현 보고서

## 결과

현재 `jump-game.js`와 `jump-patterns.js`의 기본 규칙은 v17이며 결과 mode는 `jump-distance-v17`이다. 동결된 `jump-game-v16.js`, `jump-patterns-v16.js`는 수정하지 않았다.

v17은 시작 속도 260px/s, 10초마다 +28px/s, 최고 480px/s다. 기본 장애물 목표는 10초당 7개에서 시작해 10초마다 1개씩 늘고, 여섯 생태 구간의 기존 빈도 배율을 함께 적용한다. 체력 3, 약 1000m 하트, 단계 배경, 하트 안전 통로, 입력 버퍼, 일시정지와 종료 착지 연출은 유지한다.

## 조작과 운동 시간

일반 첫 점프의 측정 체공 시간은 812ms다. 공중에서 ↓를 300ms 시점에 누르면 하강 속도를 최소 560px/s로 즉시 만들고 2600px/s² 중력을 적용해 451ms에 착지한다. 체공 시간이 약 44% 줄어든다. ↓ 눌림은 착지 뒤에도 유지되므로 캐릭터는 별도 입력 없이 바로 숙이기 판정과 자세로 이어진다. 모바일 숙이기 버튼도 같은 pointer-held 상태를 사용한다.

사용자 안내 문구는 “공중에서 ↓를 누르면 빠르게 내려와 바로 숙여요”와 시작 2.3초의 “점프 두 번 · 공중에서 ↓ 빠른 착지”만 추가했다.

## 패턴 구성과 간격

v17 전용 풀은 서로 다른 치수와 간격을 가진 100개다.

- 기본/넓은 점프 15개: 회복 거리 460px.
- 연속 숙이기 40개: 1~5개씩 각 8변형. 시작점 간격 142~170px이며 장애물 폭 104~122px다. 한 번 길게 숙이는 기술로 통과한다.
- 낮은 장애물→2단 점프 15개: 두 장애물 시작점 차이 125~157px, 최소/최고 속도에서 260~604ms다. 첫 점프 뒤 공중에서 두 번째 점프를 이어 높은 장애물을 넘는다.
- 점프→숙이기 15개: 시작점 차이 330~378px, 최소/최고 속도에서 688~1454ms다. 최고 속도에서는 일반 812ms 체공으로 늦으므로 빠른 낙하 후 즉시 숙여야 한다.
- 마스터 3연계 15개: 낮은 장애물, 130~146px 뒤 높은 장애물, 첫 장애물 기준 520~562px 뒤 숙이기 장애물이다. 점프→2단 점프→빠른 낙하→숙이기를 사용한다.

패턴 뒤 회복 거리는 기본 460px, 연속 숙이기 400px, 낮은→2단 540px, 점프→숙이기 500px, 마스터 연계 680px다. 최고 속도에서 현재 묶음 마지막 장애물 시작점과 다음 묶음 첫 장애물 시작점의 시간 간격은 각각 958ms, 833ms, 1125ms, 1042ms, 1417ms가 남는다. 기본 패턴 경계는 일반 점프 체공 812ms보다 146ms 길다. 목표 빈도가 이 거리보다 느슨할 때는 목표 주기를 사용하고, 밀도가 높아져도 이 회복 거리를 줄이지 않는다.

단계 1은 기본 점프와 숙이기 1개로 바로 시작하고, 10초 뒤 낮은→2단 변형 3개를 낮은 비중으로 섞는다. 단계 2에서 숙이기 2개와 점프→숙이기 변형 3개를 열고, 단계 3에서 낮은→2단 전체, 단계 4에서 숙이기 3개와 점프→숙이기 전체, 단계 5에서 숙이기 4~5개, 단계 6에서 3연계를 해금한다. 첫 화면에서 빠른 낙하를 설명하지만 안전 연습 구간을 길게 강제하지 않는다. 단계 또는 10초 난도가 바뀌면 덱을 다시 구성해 새 기술이 바로 등장할 수 있다.

## 검사

`node --test tests/v17-jump-physics.test.mjs` 5/5 통과:

- 일반 낙하 812ms와 빠른 낙하 451ms, 착지 숙이기 유지.
- 260→480px/s 및 10초 속도/밀도 증가.
- 여섯 단계의 1~5 연속 숙이기와 세 연계 종류 해금.
- 실제 게임과 같은 60fps 물리 단계에서 100개 모든 패턴을 260, 288, 316, 344, 372, 400, 428, 456, 480px/s의 아홉 속도마다 입력 시점 탐색으로 통과 가능함을 확인.
- 모든 임의 패턴 경계가 최고 속도에서 시작점 간격이 최소 833ms임을 확인.

`DW_TEST_URL=http://localhost:4188 node tests/v17-jump-browser.mjs`가 실제 Chromium에서 통과했다. 모바일 점프/숙이기 버튼의 pointerdown/up으로 260px/s 빠른 낙하와 착지 숙이기, 키보드 Space/↑ 2단 점프, 480px/s 낮은→2단·연속 숙이기·점프→숙이기·마스터 3연계, 일시정지 동결, 하트 획득을 확인했다. 반응형 자동 조작은 임의 패턴 경계를 포함해 6000m까지 체력 3을 한 번도 잃지 않았다. 콘솔 오류는 없었다. `/tmp/dwingul-v17-jump/`의 다섯 화면을 원본 크기로 열어 조작 안내, 캐릭터 자세, 바닥·천장 장애물 접점과 연계 간격을 직접 검토했다.

## 공유 통합 요청

- `games.js`에서 기본 및 명시적 v17은 현재 `jump-game.js`, v16은 동결 `jump-game-v16.js`로 연결한다.
- `game-options.js` 기본 버전을 v17로 올리고 `jump-distance-v17` 표시 이름을 추가한다.
- 공통 CSS의 상태 숨김 selector에 `.dg-game--jump-v17`을 추가하고 일시정지 버튼은 유지한다.

브라우저 검사는 키보드와 모바일 pointer-held 조작, 공용 pause를 모두 확인했다. 기존 v16 경로는 동결 파일로 분리되어 있다.
