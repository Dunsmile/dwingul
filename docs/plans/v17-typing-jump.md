# v17 — 타자 기록과 멀리 뛰기 연속 조작

사용자 요청: 타이핑 마스터 점수·평균 타수·제출 정확도, 쿠키런처럼 어려운 멀리 뛰기와 공중 급강하 슬라이딩.

## 결정
- 기존 타이핑 전투 규칙·장비·긴 문장 ×2는 유지. 입력 기록으로 두벌식 환산 타수를 측정하며 한글 IME 조합 중복을 자모 단위 차이로 제거한다. 한=3, 닭=4, 꽃=4. 수정 후 다시 입력한 문자는 추가 타수다. Enter·Backspace 등 제어키는 제외.
- 평균은 일시정지를 제외한 전체 플레이 시간으로 계산. 읽기·대기 시간 포함. 물리 키보드 이벤트 수와 동일하다고 주장하지 않는다. 사용자 제공 공식을 레퍼런스로 사용하며 한컴 공식 측정과 완전히 동일하다고 표기하지 않는다.
- 제출 정확도는 제출 시점의 원문과 입력을 편집거리로 비교한다. 수정 중 오타는 무관. 삽입·누락·치환을 각각 1글자 오류로 합산하고 길이가 큰 쪽을 분모로 사용. 제출 전 사망·무입력은 정확도 없음. 치명적 오타도 제출된 전체 문장으로 평가. 빈 제출·회복·변경 없는 연속 Enter 제외.
- 서버가 새 입력/확정 이벤트를 재생하여 결과를 검증. 게임 규칙은 변하지 않아 타이핑 랭킹 버전은 유지. 멀리 뛰기는 별도 v17로 구분하고 v16 엔진은 보존.
- 멀리 뛰기는 급강하/착지 슬라이딩을 먼저 구현한 뒤 물리적으로 피할 수 있는 촘촘한 묶음 장애물을 추가한다. 3 하트·6구간 유지. 물리 테스트와 실제 브라우저 조작 확인 후 배포.

## 검증
한글/NFD/겹받침/쌍자음 환산, 조합 이벤트, 오타 수정 및 제출, 치명적 제출, 회복, 재생, 프로필 결과 저장. Chromium/WebKit 모바일·PC 결과지. 멀리 뛰기 빠른 낙하·연속 슬라이드·점프 전환·최고 속도 회피 검증.
